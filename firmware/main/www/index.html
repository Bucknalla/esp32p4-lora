      Open the TTN console

      1. Register the gateway EUI above on your network server, with an EU868 channel plan.
      2. Create a key for Basics Station access. The gateway sends it as Authorization: Bearer; TLS client certificates are not supported yet.
      3. Paste the key below. It is stored on the gateway and never shown again.

    3. Add your devices

    4. Connect to an MQTT broker

      The gateway publishes your devices' uplinks and joins to an MQTT broker as JSON, and sends the downlinks it receives there. Any application that connects to the broker can use them.

      Topics and downlinks

      Topics: . The gateway id is part of every topic.

      Downlinks: publish {"id":"job-1","port":1,"payload_hex":"0102","confirmed":true} (not retained) to …/<DevEUI>/down; confirmed and id are optional; with a codec, {"object":{...}} instead of payload_hex (port optional). The gateway sends it after the device's next uplink (a class C device: at once, then one every 5 s), up to 4 per device. Needs "Local server transmit" on (Radio tab).

      Results on …/<DevEUI>/down/result, with your id: queued or refused, then sent for each transmission, then acked or nacked for a confirmed downlink. dropped if it could not be delivered. A nacked downlink is not sent again: publish it again if needed.

      Plain MQTT (no TLS): the password and data cross the network readable; use it on your own network only.

      Anyone who can publish on the broker can send downlinks to your devices: limit that with the broker's access rules. The password is stored on the gateway and never shown again.

    Local devices

    Add a device (OTAA)

    Payload codecs

    JavaScript codecs, as published for TTN and ChirpStack: a decoder (decodeUplink, or the older Decoder and Decode) and/or an encoder (encodeDownlink, Encoder, Encode); join a device's two files into one. Pick one for a device above: its uplinks then carry the decoded data as object next to payload_hex, and its MQTT downlinks may carry object instead of payload_hex. Each run is limited to 200 ms and 1 MB.
