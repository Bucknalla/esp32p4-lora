# ADR-0005: Support the SX1301 (MaxIIoT GL5712) with lora_gateway v5.0.1

- Status: accepted. Supersedes ADR-0004's "SX1302/SX1303 only".
- Date: 2026-11-21

## Context

The bench cards are MaxIIoT GL5712 (SX1301 + 2× SX1257). Using them needs no
new hardware. For the v1 goals (8 channels, EU868, Class A, ADR) the SX1301
and the SX1302 do the same job. Risks: Semtech no longer maintains
`lora_gateway`, and ChirpStack users could not start GL5712 cards on this HAT.

## Decision

- Add `firmware/components/sx1301_hal`: Semtech `lora_gateway` v5.0.1 (commit
  a955619), generated by `tools/import_sx1301_hal.py`. Patches: spidev calls
  through the port, `wait_ms` through the port, `SPI_SPEED` 2 MHz (as Nebra).
- The platform layer moves to a shared component, `lgw_port` (SPI, delays,
  fixed temperature). Both HAL components use it.
- Kconfig `GW_CONC_CHIP` selects one HAL (default SX1301). Both define the same
  `lgw_*` symbols, so the other one builds empty. At boot, the firmware
  identifies the card and starts the HAL only if the chip matches the build.
- `sx1302_hal` stays in the tree, unchanged. It is not in the default build,
  not in CI, and it has never run on hardware.
- Same warning exemption as ADR-0004 for upstream files.
- `CONFIG_GW_LGW_DEBUG` (DEBUG_HAL/DEBUG_REG) is on during bring-up:
  `lora_gateway` reports `lgw_start` errors only through these macros, and
  `lgw_start` ignores the `load_firmware` result.

## Evidence (2026-11-21, bench board, Helium HAT V1, GL5712)

- Nebra EU868 config: clksrc 1, both radios SX1257 at 867.5 / 868.5 MHz,
  RSSI offset -158, RX only.
- `lgw_start` OK in 3081 ms. Calibration status 0x9F: finished, SX1301 and both
  radios reachable, image rejection OK on both. TX DC offset was not
  calibrated (TX off).
- AGC/ARB/calibration firmware (8 KB each) loaded and read back with no
  mismatch. This proves port transfers longer than one 64-byte chunk.
- `lgw_stop` OK. HAL task stack used about 9 KB of 24 KB.

## Consequences and risks

- The design plan's "SX1302/SX1303 only; SX1301 cards are spares" needs an
  update.
- Radio B (SX125x #1) version register reads 0x90, not 0x21. Calibration
  reaches radio B, so it is accepted for now. Compare with a second card.
- TX phase: the GL5712 draws up to 700 mA at +27 dBm through the HAT's LM1117.
  Check the regulator's rating and thermal limit before TX tests. Brownout
  detection is on.
- The ChirpStack failures may have come from the 8 MHz upstream default
  versus Nebra's 2 MHz. This is not proven.
